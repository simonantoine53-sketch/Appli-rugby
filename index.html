Raccourcis clavier
  • V ou Échap : sélection
  • 1–0, S, D, F, T : outils de forme
  • Suppr : supprimer l’objet sélectionné
  • Ctrl+D : dupliquer
  • Ctrl+Z / Ctrl+Y : annuler / rétablir
  • Flèches : déplacer l’objet (Maj = plus vite)
  • Cliquer-glisser dans le vide : sélectionner tout ce qui est dans le cadre (avec Maj : ajouter)
  • Maj + clic : ajouter à la sélection ; Ctrl+A : tout sélectionner
  • Maj + glisser : déplacement aligné ; sur une ligne, angle à 0°, 45° ou 90°
  • Double-clic sur un texte ou un joueur pour le modifier

Qui crée le compte ?

Avant 15 ans, c’est un parent qui crée le compte (la loi le demande). Il pourra ensuite répondre aux convocations avec vous, et vous donner votre propre compte à 15 ans.
